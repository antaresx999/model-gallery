  1. Plugin herunterladen und entpacken. Den Ordner ModelGallery.lrplugin an einen festen Ort legen.

  3. Fotos auswählen → Datei → Exportieren → oben Exportieren auf: Model Gallery.
  4. Server-Adresse {{ public_base }} und den API-Schlüssel eintragen, Verbinden klicken, Album wählen.
